# PatchLoop documentation

PatchLoop fixes bugs with a team of AI agents and lets the tests decide. You
pick a bug; a LangGraph agent team (triage, parallel proposers, critic,
reviewer) running on Nemotron models via Nebius Token Factory proposes fixes in
parallel, each tested in its own isolated Nebius Sandbox. NeMo Guardrails and a
deterministic policy gate check the input, every patch and the output, and a
security scan flags new findings. A solved run opens a GitHub pull request with
the proof (diff + test output) and a Slack alert tells the on-call engineer,
who reviews and merges it. Agents can never merge or push to main. Everything
is also reachable from the [CLI](/docs/cli).

## Monorepo layout

```
frontend/   # Next.js: landing page, /try demo, dashboard, run pages, docs  (port 3000)
backend/    # Go + Gin + MongoDB: auth, runs, tokens, PRs, event relay     (port 8080)
agent/      # Python + FastAPI + LangGraph: agents and sandboxes          (port 8001, internal)
```

The browser and the CLI only talk to the backend; the backend is the only
caller of the agent service.

## Tech stack

| Layer | Choice |
| --- | --- |
| Frontend framework | Next.js 16 (App Router, Turbopack) |
| UI | React 19, Tailwind CSS v4 |
| Design system | In-repo components (`app/_ui`), inline SVG icons and diagrams |
| Backend framework | Go + Gin |
| Database | MongoDB |
| Auth | JWT (access + refresh) in httpOnly cookies |
| Transactional email | Resend (OTP email verification) |
| Agents | Python, FastAPI, LangGraph |
| Models | Nemotron via Nebius Token Factory |
| Sandboxes | Nebius Sandboxes |
| Guardrails | NeMo Guardrails + deterministic policy gate + security scan |
